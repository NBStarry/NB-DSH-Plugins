# 团队人数上限

本插件提供独立会话入口和 `/team-capacity` 命令，读取或修改当前 profile 所有团队的成员上限，不依赖角色管理或团队协作策略。关闭插件不会重置已经保存的上限，也不会删除成员与历史。

保存会重载团队服务，可能中断会话。保存前必须进入维护窗口，先让同一 profile 的相关会话停止任务，并在操作期间避免启动或唤醒任务。插件检查 running/provisioning 成员并临时阻止两个新建成员工具，但检查不是原子空闲锁，不能保证并发期间不会启动任务，也不能阻止所有直接服务调用、并发消息或唤醒。确认失败或超时后先检查状态，不盲目重试。

客户端入口只经过模拟测试，真实浏览器仍需验证。不要同时启用重复注册容量命令或显示重复入口的其他版本；切换前需备份并验证回滚。
