# 团队协作策略（隔离候选版本）

本包保留既有 `@local/dsh-team-only` 包名、`local-team-only` 配置行和四个可编辑字段，提供 coordinator/balanced 协调、团队工具限制、受控二级委派。角色、成员模型、人数设置和列表排序由独立插件提供；关闭角色插件时策略提醒使用原生 `list_agents`，不修改用户自定义提示词。关闭本包不删除其他插件数据，但不再限制普通委派或提供 `spawn_level2`。

配置仍由 DSH 的设置服务管理，角色数据不由本包打开或复制。协作提示作为 required runtime context 随用户角色快照传入，不是 system 指令，不提升指令优先级；当前 DSH 的 complete persona 和可选上下文抑制不会按常规装配剔除它，但其他 waterfall、请求链或兼容性变化仍可能影响实际模型输入。守卫只针对已知工具名，行为提示不是操作系统沙箱。二级工具明确配置深度 2，Host 的默认深度 1 不是硬上限。

**部署前置条件：** 此目录为未部署候选；新旧同名包及重复工具不能共存。必须先备份原包和现有配置，安排其他会话空闲，确认宿主模块更新/重启方式，在隔离 profile 测试迁移和回滚后才能切换。不要将此目录内容直接覆盖已安装链接。模型切换由独立插件提供，不增加确认；实际权限和身份校验仍生效。
