# 单题联试入口 0.1.5（隔离候选）

在本人打算领办并接收答案的普通活动根会话中输入 `/steward-trial`，不要带参数或附件。命令本身仅申请。在 Mac 确认框核对工作区路径、标识和原会话标识后，决定是否领办固定的「周报口径：合计 / 日均」。取消、超时或目标变化，不登记任务，不开始挑战。领办后须在本机和本人已绑定的 QQ 私聊完成第二阶段授权；核对码仅从 Mac 输入到机器人私聊，不给模型、不提交到 DSH 会话。已登记或试次不明则停下，不会重新弹框或发送。

本版采用 stock `@deepseek-ai/dsh-home-paths` 的数据根约定：没有非空 `DSH_HOME` 时使用 `os.homedir()/.dsh`；显式配置只接受现存安全绝对目录。两种情况均沿用 `steward-host-private`，不迁移或清零旧库。插件独立目录不保证可解析宿主工具包，故只使用 Node 内置 API，无新增安装依赖。没有已挂接的连接能力时不开始领办；等待期间换代不登记。

无模型工具，无公开领办参数。Host 启动时不扫描/发起/定时处理。保留 SQLite 固定首个试次和原根回读；持久接收不等于任务已完成。正常退出后，未完成的登记/未知试次须人工核对，不能重新发起。非 macOS 无法领办。安装和真实联试另行授权。
